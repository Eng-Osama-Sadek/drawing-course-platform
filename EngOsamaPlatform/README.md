## Project Overview
This platform serves as a comprehensive educational hub tailored for Prep Engineering students, Fine & Applied Arts students, and Technical Institutes. It features:
- **Scalable Video Recording:** Integrated WebRTC capabilities allowing the instructor to open the camera, record boundless video sessions, and interface them directly with cloud storage (Google Drive).
- **Secure File Distribution:** A gated backend architecture protecting PDFs, Images, Word, and Excel files. Access is algorithmically granted only upon administrative approval.
- **Automated Notification & Access Management:** Direct dashboard controls to handle user subscriptions and manual verification of Vodafone Cash payments (+201024519686).
- **Professional UI/UX:** Designed with optimal visual contrast (deep blue and light yellow) to maintain student focus during prolonged study sessions.

## Tech Stack & Automation
- **Backend:** Python (Flask) - Built cleanly for rapid expansion and continuous integration via AI developer engines.
- **Frontend:** HTML5, CSS3, JavaScript (MediaRecorder API for live camera streaming).
- **Deployment & Cloud:** Configured for seamless API integration with Google Drive for unmetered video storage and retrieval.

## How to Run (Local Development)
1. Ensure Python 3 is installed.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the application: `python app.py`
4. Access the platform at: `http://localhost:5000`
5. Access the Admin Dashboard at: `http://localhost:5000/admin`
